# ATSPM documentation generator

This repository contains the source-only GitHub Action that generates ATSPM
configuration and logger-message documentation. It reads C# source with Roslyn,
writes deterministic Markdown pages, and validates the result with MkDocs.

The generator is consumed directly from this repository. It is not published as
a NuGet package, container image, or registry artifact.

## Repository layout

- `action.yml` defines the composite GitHub Action.
- `src/GenerateDocuments` contains the .NET 8 command-line generator.
- `tests/GenerateDocuments.Tests` contains parser, validation, and snapshot tests.
- `config` contains the documented container map and its JSON Schema.
- `overrides` contains the MkDocs navigation and export customizations.
- `.github/workflows/ci.yml` validates the generator and exercises the action.
- `integration` contains the caller-workflow template for ATSPM.

The generated Markdown belongs to the consuming ATSPM repository under
`docs/autogenerated`; it is not committed to this repository.

## GitHub Action usage

The calling workflow must check out ATSPM and set up .NET 8 and Python before
invoking the action. Pin the action to a full commit SHA.

```yaml
- name: Check out ATSPM
  uses: actions/checkout@v6

- name: Set up .NET
  uses: actions/setup-dotnet@v5
  with:
    dotnet-version: 8.0.x

- name: Set up Python
  uses: actions/setup-python@v6
  with:
    python-version: "3.11"

- name: Generate documentation
  uses: avenueconsultants/atspm-documentation-generator@<full-commit-sha>
  with:
    source-root: .
    output-root: docs/autogenerated
    repository-url: https://github.com/${{ github.repository }}
    repository-ref: ${{ github.sha }}
```

Inputs:

| Input | Required | Default | Description |
| --- | --- | --- | --- |
| `source-root` | No | `.` | Checked-out ATSPM source directory. |
| `output-root` | No | `docs/autogenerated` | Dedicated generated Markdown directory. |
| `repository-url` | Yes | - | Repository URL used in source links. |
| `repository-ref` | Yes | - | Commit SHA used in source links. |
| `validate-site` | No | `true` | Run a strict MkDocs build after generation. |

The action replaces the output directory transactionally, removing stale
Markdown only after generation succeeds.

## Local development

Requirements:

- .NET 8 SDK
- Python 3.11 or newer

From this repository root:

```powershell
dotnet test GenerateDocuments.sln
python -m pip install --requirement requirements.txt

$sourceSha = git -C C:\path\to\udot-atspm rev-parse HEAD

dotnet run --project src/GenerateDocuments -- `
  --source-root C:\path\to\udot-atspm `
  --output-root C:\path\to\udot-atspm\docs\autogenerated `
  --map config/container-config-map.json `
  --repository-url https://github.com/utahudot/udot-atspm `
  --repository-ref $sourceSha

$env:DOCS_DIR = "C:\path\to\udot-atspm\docs\autogenerated"
python -m mkdocs build --strict
```

Initializer expressions such as `System.IO.Path.GetTempPath()` are documented
as source text and are never executed. Source links continue to target the exact
ATSPM revision supplied through `repository-ref`.

## Updating ATSPM

Copy `integration/atspm-update-autogenerated-docs.yml` to
`.github/workflows/update-autogenerated-docs.yml` in ATSPM, replace
`REPLACE_WITH_COMMIT_SHA` with the pinned commit from this repository, and run
the workflow manually once before enabling its push trigger.

For a private repository, configure **Settings -> Actions -> General -> Access**
so the ATSPM repository can use this action.
