# ATSPM documentation

This site contains generated configuration reference material for the open-source
Automated Traffic Signal Performance Measures platform.

[View the ATSPM source repository](https://github.com/utahudot/udot-atspm)

The [configuration reference](configuration/index.md) is generated directly from
the configuration classes in a specific ATSPM commit. Every generated page links
back to the exact source revision it describes.
